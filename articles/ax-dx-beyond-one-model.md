:::message

- 環境が整っていても、ハードル（段階）を越えるたびに、技術の限界や現実の制約で、実現できる確率は理想より少しずつ下がります

LLMやエージェントが出てきて、AIを使うハードルはMLのころよりずっと低くなりました。生活でも仕事でも、その変化ははっきり感じるところです。

でも、いろいろな現場や身近な人の話を聞くと、少し様子が違います。会社では「AIを入れたのに、現場は変わらない」と聞きますし、個人で試してみたけれど、何に使えばいいか分からなくてやめた、という声もよく聞きます。同じ技術なのに、どうしてこんなに違うのでしょうか。自分の経験から考えてみました。

## どこで止まってしまうのか

会社でも個人でも、よく聞く悩みは似ています。

- 最新のモデルや、高性能なエージェント向けLLMが使えない
- コストや社内ルールのせいで、使いたい環境で動かせない
- AIに詳しい人は現場を知らないし、現場に詳しい人はAIをあまり使ったことがない
- じっくり整理して、作ってみる時間がない

一つずつ片づければよさそうな話です。でも、AX/DXを本当に実感するには、これが全部いっしょに、同時に動かないといけないのではないでしょうか。

## 自作の「ブリーフィング」を例に

筆者は、「ブリーフィング」と一言送るだけで整理してくれるアシスタントを二つ使っていて、一つは個人サーバー、もう一つは業務用サーバーで動いています。どちらも、これまでの使い方やためてきた知識をもとに、そのときに必要な情報を選んでくれます。

![二つのブリーフィング。個人サーバーはためてきた知識から週末に学ぶテーマを、業務用サーバーはある日の朝の予定と変更、確認することを整理する](/images/ax-dx-gates/ax-dx-gates-briefing-ja.png)

毎日使えるようになるまでには、いくつかの段階がありました。

| 段階 | チェックすること | 自分の場合 |
|---|---|---|
| ① 開かれたモデル環境 | 高性能なエージェント向けLLMを使えるか | 個人は契約して、会社は社内ルールの中で使う |
| ② ドメイン×技術 | 仕事とAIの両方が分かるか | 自分の生活と仕事。AIも触ってきた |
| ③ コスト・セキュリティ | データに合う環境があるか | データごとに合う環境で動かす |
| ④ モデルの選び方 | 仕事に合うモデルを選べるか | 生成AI・MCP・スキル・機械学習から選ぶ |
| ⑤ 時間・工数 | じっくり企画して作る時間があるか | 企画は自分、開発は生成AI、確認は人 |
| ⑥ 実際の運用 | 使いながら改善し続けられるか | SaaSなしで数か月。知識もたまっていく |

どれか一つでも欠けていたら、「一回試してみた」で終わっていたと思います。モデルが良くても、何が大事か分からなければ関係ないことまで整理してしまいます。データを合う環境で動かせなければ、そもそも始められません。

ブリーフィング以外にも、同じやり方で作って使っているものがあります。

| 区分 | 作って使っているもの |
|---|---|
| 個人 | このブログの執筆、スケジュール管理、趣味の開発など |
| 仕事 | 自分好みの要約・整理・分析と資料作り |
| 仕事 | オンボーディング用ページ（反映と更新は自動、確認は人） |
| 仕事 | 案件管理とデモ作りの自動化（セキュリティに合わせてモデルを使い分け） |

どれも完成品ではありませんが、**考えたことの半分以上は、実際に使えています。**

## ハードルを越えるたびに、理想より少しずつ下がっていく

**環境が整っていても、ハードル（段階）を一つ越えるたびに、実現できる確率は理想より少しずつ下がっていきます。** 技術の限界や現実の制約があるからです。どこかにボトルネックがあれば、もっと急に下がります。

冒頭のグラフは、これを自分の感覚で数字にしてみたものです。環境がよく整った個人や企業なら、半分以上は実現できると考えました。

| 環境 | 設定 | 最後に残るのは |
|---|---|---|
| AX/DXに近づいている個人・企業 | 最適な環境でも、技術の限界と人の確認で、段階ごとに約10%減る | 半分以上 |
| ボトルネックのある環境 | 制約で試す機会もリテラシーも減り、段階ごとに30%以上減る | 約10% |

一つの段階では小さな差でも、重なると大きく開きます。よく整った側でも、半分近くは実現しません。技術の限界はやっぱりありますし、人が必ず確認すべきところもあるからです。

ボトルネックのある側は、事情が少し違います。制約が多いとAIを実際に触る機会が少なく、そのぶんリテラシーも育ちません。結果として、次のハードルでもまたつまずいてしまいます。

## モデルや技術、サービスだけで変わる？：人と文化もいっしょに変わらないと

予算をかけて良いモデルを入れても、使う人の働き方が変わらなければ、何も変わりません。働き方を変えようとしても、試す時間や環境がなければ、また止まってしまいます。技術、ドメイン知識、AIを使う力、実行環境、コスト。どれも、ばらばらには解決しませんでした。

**結局のところ、文化と人の意思決定もいっしょに変わって、はじめてAIを現場でちゃんと使えるようになるのだと思います。**

これは会社に限らず、個人も同じです。次の質問に答えてみると、どこで止まっているのか、一つの段階だけ先に進んでいないかが見えてきます。

| 段階 | 自分に聞いてみること |
|---|---|
| ① | 高性能なエージェント向けLLMを使えるか |
| ② | 仕事が分かる人とAIが分かる人が同じ場にいるか（個人なら、両方分かるか） |
| ③ | データに合った実行環境があるか |
| ④ | 仕事ごとに合うモデルを選んでいるか |
| ⑤ | じっくり企画して作る時間を取れているか |
| ⑥ | 使いながら直し続けられているか |

## 自分が気をつけていること

AIを使うとき、個人的に大事にしているのは、技術のレベルだけではありません。

いちばん大きいのは、ドメインとAI技術をつなげる力です。よく知っている分野や仕事の流れに、どのAI技術が合うかが分かっていたので、始める前に「できそうか」を判断できました。判断するときは、だいたい次のところを見ています。

- いまの状態（入力）と、目指す姿（出力）、その差を言葉にできるか
- その差を細かく分けて、それぞれに合う技術を当てはめられるか
- 間違えても大丈夫な仕事か、最後に人が確認できるか
- データを外に出しても大丈夫か

いろいろなモデルを、合う環境で使えるインフラも大きな助けになりました。ローカルとクラウド、自社モデルとフロンティアモデル、LLMとDocument AIまで選べたので、データやセキュリティの条件で一つが使えなくても、別のものに切り替えられました。おかげで、開発のハードルはかなり下がっています。

## AIの天井は上がり続けている

いま100としたAIの天井は、ずっと同じではありません。モデルが良くなるたびに、150、200と上がっていきます。最近はそのペースもどんどん速くなっていて、**ほぼ毎日のように新しいモデルが出ています。**

![天井が100、150、200と上がったときに、二つの環境に残る値とその差](/images/ax-dx-gates/ax-dx-gates-ceiling-ja.png)

最新のモデルを使い続けてきた人や組織は、新しいモデルが出てもすぐに慣れて、使いこなすまでが早いです。そうでないところは試す機会が少なく、AIのリテラシーが少しずつ足りなくなっていきます。実際の差は、グラフよりも速く開くかもしれません。

## 人・文化・インフラ・業務をいっしょに

ここまでの段階のうち、技術だけで解決できるものはそう多くありません。個人の考え方や組織の文化が変わって、関係する人たちとよく話しながら、いっしょに動いていく必要があります。AIを試せるインフラや投資も、その結果を受け入れられる働き方も欠かせません。**人・文化・インフラ・業務がいっしょに動いたとき**に、やっとAX/DXを実感できるのだと思います。

一人の経験から出た考えですが、止まっている段階を一つずつほどきながら、ほかの段階もいっしょに動かしていけば、すぐにとはいかなくても、AIの活用を実感できるところまでは行けるのではないでしょうか。
